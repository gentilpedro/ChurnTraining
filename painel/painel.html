Qualidade do modelo

Conjunto de teste, sempre os mesmos 2.000 clientes — os filtros de país, atividade e busca não mexem aqui, só o corte.

Onde o churn se concentra

Percentual que de fato cancelou em cada grupo, apurado no histórico — não é previsão. A linha vertical marca a média da carteira filtrada.

No que o modelo se apoia

Peso de cada característica nas decisões da árvore. Tempo de casa, salário e cartão quase não contam — idade e número de produtos decidem quase tudo.

De onde vêm os números

Bank Customer Churn Dataset (Kaggle, gauravtopre): 10.000 correntistas, 2.037 deles cancelaram. Banco Avenida é um nome fictício sobre esses dados.

Uma ressalva honesta

8.000 destes clientes foram usados para treinar a árvore, e nessas linhas a nota sai otimista. O botão “Só quem ficou fora do treino” restringe a carteira aos 2.000 que o modelo nunca viu — é essa visão que se parece com produção.

Como regerar

docker compose run --rm trainer refaz o treino e reescreve esta página em models/painel.html com as notas novas.
